📂 Open Capture Tab
  1. Click the button above to open the Capture Tab
  2. Keep it next to your casino window (side by side)
  3. When a winning number appears, type it in the Capture Tab
  4. Press Enter — number is saved immediately
  5. You verify every number before sending (no automation errors)

🔌 Future Integration

This capture project is fully independent. When you're ready to integrate with the main dashboard:

The capture server stores all spins in spins.json (same directory). Your main dashboard can either:

  • Poll GET http://localhost:8081/api/spins for new numbers
  • Read spins.json directly if both servers share a filesystem
  • Auto-forward by adding a webhook callback in the capture-server

No changes needed to your existing dashboard files.

⚙ Running the server

Open a terminal in the roulette-capture folder and run:

python capture-server.py

Keep the terminal window open while you play. The server runs on port 8081.
